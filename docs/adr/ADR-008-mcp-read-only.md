# ADR-008: MCP-сервер лише для читання

- **Статус:** прийнято
- **Дата:** 2026-10-29
- **Тікет:** ACKEE-27 (US-K1, епік EP-K)

## Контекст

Користувач AI-асистента хоче запитати статистику природною мовою: «скільки відвідувачів було вчора», «звідки приходять на shop.example.com». Асистент потребує інструментів із чіткими аргументами, а Ackee – гарантії, що через нового клієнта не можна нічого змінити й що кожен запит видно в журналі дій. Протокол MCP молодий і змінюється (на дошці – ризик «фіксуємо версію»).

## Рішення

- **Ендпоінт у тому ж процесі:** `POST /mcp` поруч з `/api` (Streamable HTTP, без сесій: сервер і транспорт на кожен запит). Інструменти виконують фіксовані GraphQL-запити звітів **у процесі**, через ту саму схему і резолвери, що й `/api`, з контекстом того ж viewer. Жодних других правил доступу.
- **Лише читання за побудовою:** асистент передає лише значення з переліків (домен, вимір, діапазон, інтервал), ніколи запит чи ім'я поля. Шість інструментів: `domains`, `report`, `top`, `live`, `events`, `compare`. Мутації недосяжні, бо жоден запит їх не містить.
- **Авторизація токеном API:** `Authorization: Bearer` з постійним або сесійним токеном, resolveViewer як для `/api`; без токена – 401 і більше нічого. Токен акаунта без доменів бачить порожній список.
- **Журнал:** кожен виклик – запис `mcp.<tool>` в `auditlogs` простору домену (або першого простору viewer) з аргументами; простору немає – нічого не пишемо й нічого не показуємо.
- **Версія зафіксована:** `@modelcontextprotocol/sdk` 1.32.2 без карета (протокол `2025-11-25`).

## Альтернативи

- **Окремий процес через GraphQL по HTTP** – ще один сервіс, свій токен, свій деплой; будь-яка зміна схеми ламає його окремо. Відкинуто.
- **stdio-сервер на машині користувача** – потрібен Node і токен на кожному робочому місці, журнал на сервері вести не можна. Відкинуто.
- **Інструмент «виконай GraphQL»** – один інструмент замість шести, але тоді мутації досяжні, а обмежувати їх списком – крихко. Відкинуто.

## Наслідки

- Два нові пакети в образі (`@modelcontextprotocol/sdk`, `zod`); оновлення SDK – зміна на рев'ю, не рутинний bump.
- `countries` з ACKEE-100 треба додати до переліку вимірів `top` після злиття.
- Live-стрічка (SSE) асистенту не віддається: `live` повертає факти з `facts`.
