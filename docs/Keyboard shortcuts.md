# Keyboard shortcuts

## Switch between views

In Ackee, you can quickly switch between views using the following keyboard shortcuts.

| Key     | View      |
| :------ | :-------- |
| `o`     | Overview  |
| `0`…`9` | Domain    |
| `v`     | Views     |
| `p`     | Pages     |
| `r`     | Referrers |
| `d`     | Durations |
| `e`     | Events    |
| `l`     | Live      |
| `s`     | Settings  |

## Switch between tabs

Traffic and Audience show their reports in tabs. The following keys are supported when a tab is focused.

| Key     | Action                                         |
| :------ | :--------------------------------------------- |
| `→` `←` | Next or previous tab, wraps around at the ends |
| `home`  | First tab                                      |
| `end`   | Last tab                                       |

## Interact with the menu

On a narrow screen the navigation opens as a menu.

| Key   | Action     |
| :---- | :--------- |
| `esc` | Close menu |

## Interact with modals

The following keys are supported when a modal is focused.

| Key     | Action        |
| :------ | :------------ |
| `enter` | Confirm modal |
| `esc`   | Close modal   |
